# Пассивный анализатор сетевого трафика.
Сниффер (анализатор трафика) — это специальная программа или аппаратное устройство для перехвата, сохранения и анализа данных, которые передаются по компьютерной сети.

## что он делает? 
Перехватывает TCP, UDP, ICMP пакеты. Для TCP: определяет операционную систему по TTL, Window Size и опциям (MSS, SACK, Timestamp, Window Scale), вычисляет расстояние в хопах, показывает DF и IP ID. Для UDP и ICMP: выводит базовую информацию (адреса, порты, длину, тип ICMP-сообщения). Фильтрует трафик по протоколу и порту (через BPF). Завершается после заданного количества SYN-пакетов или по Ctrl+C с выводом статистики

## зависимости
- libpcap (dev)
- gcc (или clang)

## компиляция и запуск
```bash
gcc -o net-analyzer main.c -lpcap
sudo ./net-analyzer
```

## опции
| Опция | Действие |
|-------|----------|
| `-i <интерфейс>` | Интерфейс для прослушки (по умолчанию: выбирается первый) |
| `-c <количество>` | Завершиться после N SYN-пакетов (по умолчанию: бесконечно) |
| `-p <tcp/udp/icmp>` | Фильтр по протоколу (по умолчанию: tcp) |
| `--port <номер>` | Фильтр по порту (для tcp и udp) |
| `-h` | Справка |


## тестовый инструмент
В папке `tools/` находится `synsend` — утилита для отправки SYN-пакета. Используется для проверки работоспособности сниффера.

### компиляция клиента (synend)

```bash
cd tools
gcc -o synsend synsend.c -lnet
```

### зависимости для synsend
- libnet (`brew install libnet` на macOS, `sudo apt-get install libnet-dev` на Linux)

2. В другом терминале отправить тестовый SYN: `sudo ./tools/synsend 93.184.216.34 80`
3. Сниффер должен показать отправленный пакет.
